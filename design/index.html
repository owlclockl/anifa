Что можно потрогать

  • Вкладки «Заметки / Папки / Поиск / Настройки» переключают экраны.
  • Клик по заметке открывает редактор; стрелка «назад» возвращает.
  • Чек-лист в редакторе отмечает пункты; «Добавить пункт» создаёт новый.
  • Кнопка «+» открывает шторку «Новая заметка».
  • В настройках тема переключается на тёмную — интерфейс меняется целиком.
  • Поиск фильтрует заметки по мере ввода.
Векторные артборды (design/svg/*.svg) импортируются в Figma как редактируемые векторы: File → Import или перетаскиванием в канвас. PNG-версии — design/png/, иконка приложения — app-icon.
