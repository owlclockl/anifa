# Искра — тренажёр головоломок

Мобильное веб-приложение на русском языке, адаптированное для Android и установки на главный экран как PWA.

## Запуск

Откройте `index.html` в браузере или запустите статический сервер в корне проекта, например:

```bash
python3 -m http.server 8000
```

Для установки на Android откройте сайт по HTTPS в Chrome и выберите **⋮ → Установить приложение** (или **Добавить на главный экран**). После первого посещения приложение работает офлайн. Для публикации по HTTPS можно использовать любой статический хостинг.

## Что внутри

Каждая серия содержит десять разных заданий: уравнение, числовой ряд, анаграмму, судоку 4×4, логическую цепочку, загадку, выбор математического знака, поиск лишнего, визуальный паттерн и геометрию. Есть три уровня сложности, проверка ответов, подсказки, разбор решения, пропуск заданий, локальная статистика и необязательные звуковые сигналы. Все задачи и проверка ответов выполняются в браузере; аккаунт и сервер не нужны.
