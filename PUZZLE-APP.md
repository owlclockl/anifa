# Искра Судоку

Мобильная Sudoku-игра на русском: настоящая сетка 9×9 с четырьмя сложностями, быстрым вводом цифр, режимом карандашных заметок, отменой хода, подсказками и показом решения. Подсветка помогает следить за строкой, колонкой, квадратом 3×3, одинаковыми цифрами и ошибками.

Партия, таймер и личная статистика сохраняются на устройстве. APK работает офлайн и поддерживает Android 6.0+.

## Запуск веб-версии

```bash
python3 -m http.server 8000
```

Откройте `http://localhost:8000`. Для установки PWA на Android используйте HTTPS и меню Chrome → **Установить приложение**.

## Android APK

Нативная Android-оболочка находится в `android/`. APK собирается GitHub Actions workflow `.github/workflows/android-apk.yml`; готовый файл находится в `apk/iskra.apk`.
