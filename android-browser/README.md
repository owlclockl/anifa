# Slate Browser

Браузер для Android, полностью написанный на Rust. Весь интерфейс — это
Makepad UI (Rust + Splash DSL); страницы рендерит нативный Android WebView,
подключённый через Makepad native layer. Свой JNI-код не нужен.

## Что здесь есть

- **Правая колонка сайтов на всю высоту экрана.** Шесть плиток 48 dp с
  настоящими фавиконами сайтов в узком рельсе 64/72/84 dp; если фавикон не
  загрузился, остаётся нейтральный локальный знак. Плитки можно заменить
  своими адресами через `Settings → Edit site rail`, отдельно или все сразу.
  Для пользовательских сайтов показывается подпись вместо фавикона.
- **Три вкладки** в верхней строке с тонким активным индикатором и подписью
  домена, адресная строка, назад/вперёд/перезагрузка/домой. Кнопки назад и
  вперёд отключаются, когда перехода нет; тонкая полоса показывает загрузку.
  Переключение вкладок анимируется за 180 мс easing без пружин и параллакса.
- **Свой поиск Slate Search.** Вместо готового поисковика приложение само
  запрашивает DuckDuckGo HTML и Bing, собирает результаты, убирает дубликаты
  и показывает собственный список. Источники выбираются в настройках:
  оба, только DuckDuckGo или только Bing. API-ключи не нужны; парсинг HTML
  нестандартизован и может потребовать правки при смене разметки источников.
- **Стартовая страница** с поиском и частыми сайтами — чистый экран, без пляша.
- **История** (24 последних адреса) с очисткой и пустым состоянием.
  **Настройки**: тема, акцент, ширина рельса, подписи, поисковая система,
  уровень движения, источники поиска и редактирование рельса. Всё сохраняется через Makepad
  Storage; старые настройки `slate-v1` автоматически читаются как `slate-v2`.
- **Аппаратная кнопка «Назад»** сначала ведёт по истории страницы, потом
  возвращает на стартовую страницу.

Дизайн следует скиллу `unslop`: графитовая палитра (почти чёрный фон,
тёмно-серые поверхности), спокойный хром, один акцент, никаких градиентов,
свечений и эмодзи; насыщенность отдана содержимому сайтов. Стартует чистая
вкладка без наложения панелей; за раз видна только одна поверхность.

Иконки взяты из набора [Lucide](https://github.com/lucide-icons/lucide)
(ISC License, копия лицензии: `resources/icons/LICENSE-lucide.txt`).

## Сборка

Локально нужны Rust и Android toolchain Makepad:

```sh
cargo install --git https://github.com/makepad/makepad --rev 506ec05105b9adb08d1d21f9879df181b5244ea7 cargo-makepad
cd android-browser
cargo makepad android --abi=aarch64 toolchain-install
cargo makepad android --abi=aarch64 --package-name=com.owlclockl.slate.browser --app-label="Slate Browser" build -p slate-browser --release
```

APK появится в `android-browser/target/makepad-android-apk/`. В репозитории
есть workflow `.github/workflows/build-slate-browser.yml`, который делает то
же самое в GitHub Actions и выкладывает APK артефактом.

## Настройка

Значения по умолчанию и списки сайтов заданы константами в `src/main.rs`
(`SITES`, `ENGINES`, `Settings::default`). Пользовательские настройки меняются
в интерфейсе: кнопка шестерёнки в нижней части правого рельса.

Пакет: `com.owlclockl.slate.browser`, приложение: `Slate Browser`.
