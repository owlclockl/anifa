# Лунный орган — «Сердце машины»

[Смотреть ролик (MP4)](../moonspire-organ.mp4) · [Скачать музыку (MP3)](../moonspire-organ.mp3) · [Схема Litematica](../moonspire-organ.litematic) · [Общий вид](../moonspire-organ-preview.jpg)

Оригинальная пьеса в фа-диез миноре для **восьми партий нотных блоков**. В ней 20 тактов на 100 BPM: флейтовая мелодия, встречный мотив, арпеджио арфы, гитара, бас и три ударных. Пьеса постепенно наращивает ритм, ослабляет его в середине и возвращает все восемь партий в кульминации.

**Ролик с музыкой — синхронный рендер, не запись клиента.** Он показывает геометрию `.litematic` целиком, а во время игры — отдельные ярусы. Цветные вспышки отмечают звучащие ноты. Звук собран из ванильных тембров Minecraft по той же партитуре, с лёгким пространственным миксом и балансом громкости. В самой игре громкость пространственная и зависит от позиции слушателя. Партитура идёт **48 секунд** при 20 TPS; MP4 длится **50,8 секунды** вместе с заставкой и хвостом звука.

## Как запустить в Minecraft

1. Загрузи `moonspire-organ.litematic` через **Load Schematics** в Litematica для **Minecraft Java 26.3**. Вставь конструкцию целиком на пустом участке, сохраняя состояния блоков и NBT таблички. Габарит — **56 × 39 × 59** (X × Y × Z); одни контуры голограммы звук не издают.
2. Поднимись по центральной тёмной лестнице со стороны открытого торца. На площадке нажми кнопку у таблички **«Пуск»** и слушай с площадки: она находится внутри конструкции, недалеко от всех пяти ярусов. При невращённой вставке кнопка смещена на `(27, 18, 28)` от начала схемы. Проверь громкость категории «Музыкальные блоки» («Jukebox/Note Blocks») и дистанцию симуляции: все чанки органа должны тикать.
3. Одно нажатие проигрывает пьесу один раз. Не нажимай повторно, пока предыдущая дорожка не погаснет — около **50 секунд при 20 TPS**. Схема не зациклена. Команды, датапаки и пользовательские звуки для запуска не нужны.

## Как устроено

**829 нотных блоков** настроены на ноты конкретных партий. В каждом из **320 шагов** есть контрольная лампа. Кнопка запускает импульс по цепи повторителей; на каждом шаге редстоун включает только назначенные этой позиции ноты. Ноты одного шага звучат одновременно. Концы дорожек разворачиваются, а четыре перехода между ярусами поднимают импульс по винтовым проводам. Подъёмы занимают столько же тиков, сколько заложено в партитуре, поэтому темп на стыках не меняется. Над каждым нотным блоком оставлен воздух.

Из выпущенной схемы тест заново восстанавливает соединения проводов, запасы сигнала, положения нот, тембры и задержки повторителей. Все 829 нот и 320 ламп сверены с партитурой по тику. На ванильном сервере **Java 1.21.11** те же блоки прошли нативную проверку: перед своим моментом каждая нота и лампа были выключены, в нужный тик включились и после пьесы снова выключились. Для стенда менялся только формат временного шаблона; файл Litematica остаётся для **Java 26.3**, на сервере этой версии проверку не запускали. MP4 и MP3 декодированы и сверены по звуку: в ролике та же дорожка начинается после заставки.

## Пересборка

```sh
python -m pip install -r requirements.txt
python -m tools.build_organ --preview moonspire-organ-preview.jpg
python -m unittest discover -s tests -p 'test_organ.py'
```

Для пересборки медиа нужны каталог `assets/minecraft` от Java 26.3 (модели, текстуры, `sounds/note`), шрифты DejaVu, компилятор C и FFmpeg с H.264, AAC и MP3. При отсутствии FFmpeg в `PATH` можно поставить `imageio-ffmpeg`:

```sh
python -m tools.render_organ /путь/к/assets/minecraft
```

Нативный тест принимает оригинальный `server.jar` Java 26.3 или 1.21.11 и подходящую Java. Прочитай [Minecraft EULA](https://aka.ms/MinecraftEULA) и, если согласен, запусти:

```sh
python -m tools.verify_organ --java /путь/к/java --server /путь/к/server.jar --accept-minecraft-eula
```

Исходные игровые звуки и текстуры отдельно не распространяются; в репозитории лежат готовые рендеры и микс оригинальной пьесы.
