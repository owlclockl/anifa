# Лунная змейка

[Скачать схему `.litematic`](../moonspire-snake.litematic) · [Экран крупным планом](../moonspire-snake-preview.jpg) · [Демо партии (GIF)](../moonspire-snake.gif)

Отдельная пошаговая игра для **Minecraft Java 26.3**. Сплошной экран **72 × 72 блока** собран из краснокаменных ламп, а игровое поле — **6 × 6 клеток**. Тело змейки занимает **ровно одну лампу в ширину**, включая повороты. Тёмный фон тоже состоит из ламп: между клетками нет перегородок. Для игры не нужны командные блоки или датапаки.

Демо отрисовано по блочной геометрии схемы с сокращёнными паузами, а не записано в реальном времени.

## Установка

1. Положи `moonspire-snake.litematic` в папку `schematics` клиента с совместимой версией Litematica. Загрузи файл через **Load Schematics** и создай размещение на пустом участке. Габарит всей схемы вместе с пультом и проводкой — **326 × 139 × 414 блоков** (X × Y × Z).
2. **Вставь схему целиком** в творческом режиме с правами на вставку, сохраняя состояния блоков и NBT компараторов и табличек. Одна голограмма не работает. Ставь новую версию **на чистое место**, а не поверх предыдущей: проводка и положение экрана изменились.
3. Убедись, что **все чанки схемы тикают**, включая дальние участки за экраном. Например, для невращённой вставки с началом в `(0, 72, 0)` оператор может использовать:

   ```mcfunction
   /forceload add 0 0 127 413
   /forceload add 128 0 255 413
   /forceload add 256 0 325 413
   ```

   Для другого начала смести границы. Если все чанки уже тикают благодаря дистанции симуляции, эти команды не нужны. После игры можно снять загрузку тех же прямоугольников через `/forceload remove`.
4. Встань на площадку перед экраном, у пяти подписанных кнопок. В примере выше кнопки находятся на `Y=82`, `Z=7`, около `X=43`. Если после вставки стартовая картинка не появилась, дай цепи успокоиться, нажми **«Новая игра»** и дождись лампы «Готово».

## Как играть

- Кнопки **↑, ←, ↓, →** сдвигают змейку на одну клетку за нажатие. Автоматического движения нет. После нажатия дождись, пока индикатор **«Готово»** погаснет и снова загорится. Он гаснет не сразу: сигнал идёт по проводке. Ход или сброс занимает **около 59 секунд при 20 TPS**; при просадках TPS — дольше.
- Тело — непрерывная линия толщиной **один блок**. Индикатор **сверху** показывает столбец головы, индикатор **справа** — её строку. На самом поле голова не шире тела. Яблоко — отдельная фигура с черенком. Четыре квадрата под полем показывают, сколько яблок собрано.
- Начальная длина — **3 клетки**. Собери **четыре яблока в фиксированном порядке**: с каждым тело растёт на клетку. Яблоко, оказавшееся под телом, загорается, когда клетка освободится. За четвёртое яблоко загорается **«Победа»**.
- При ударе о край или собственное тело загорается **«Столкновение»**. Разворот прямо в шею игнорируется. На клетку хвоста можно зайти, если хвост уйдёт с неё этим ходом.
- После победы или поражения стрелки не меняют поле. **«Новая игра»** возвращает змейку, счёт и яблоки в стартовое состояние.

## Устройство и проверка

В схеме **806 824 блока без воздуха**, в том числе **5 184 лампы поля** и **304 лампы индикаторов**. В центре каждой игровой клетки — одна лампа тела. Между соседними центрами — дорожка из 11 ламп, которая загорается, только если клетки идут подряд в теле. Поэтому сблизившиеся голова и хвост не сливаются. Лампы получают питание с обратной стороны, не засвечивая соседние дорожки.

Координаты семи сегментов, флаги яблок и столкновения хранятся в **47 битах памяти на запираемых повторителях**. Импульс от кнопки запускает две фазы: первая фиксирует вычисленный ход, вторая переносит его на выход памяти. Лампа «Готово» загорается с запасом на обновление табло. Удержание кнопки не генерирует новых ходов.

Логика схемы сверена с правилами на **8 922 достижимых состояниях и 44 610 переходах**. Нативный тест ставит схему на официальном сервере Java 26.3 с обычными обновлениями блоков, подаёт импульсы на кнопки и проверяет все **5 488 ламп**, включая те, что должны остаться тёмными. Он проверяет повороты и края поля, сближение головы и хвоста, рост, оба столкновения, скрытое яблоко, победу, сброс и блокировку повторного хода. На контрольном ходе «Готово» вернулось примерно на **1 171-м игровом тике**. Команды используются только в тестовом стенде.

```sh
python -m pip install -r requirements.txt
python -m unittest discover -s tests -p 'test_snake.py'
python -m tools.build_snake --routing-cache /tmp/snake-routes.txt --preview moonspire-snake-preview.jpg
```

Для сборки нужен компилятор C++17. Роутер прокладывает проводку, а экспортёр проверяет связи, силу сигнала и интервалы записи. Для нативной проверки нужны официальный `server.jar` 26.3 и совместимая Java. Прочитай [Minecraft EULA](https://aka.ms/MinecraftEULA) и, если согласен, запусти:

```sh
python -m tools.verify_snake --java /path/to/java --server /path/to/server.jar \
  --neighbor-updates --accept-minecraft-eula
```
