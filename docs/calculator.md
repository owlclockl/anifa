# Лунный арифмометр

[Схема Litematica](../moonspire-calculator.litematic) · [GIF: табло и шкала в работе](../moonspire-calculator.gif) · [Крупный план пульта](../moonspire-calculator-preview.jpg)

Ванильный редстоун-калькулятор для **Minecraft Java 26.3**. На входе два 8-битных числа и код операции; на выходе — **пять десятичных цифр из ламп**. Внизу остались 16 двоичных ламп для диагностики. Командные блоки и датапаки не нужны.

## Как пользоваться

1. В группах **A7–A0** и **B7–B0** набери числа от `0` до `255`. Включённый рычаг равен `1`; веса от `128` до `1` подписаны. Например, для `197` включи `128 + 64 + 4 + 1`.
2. Выбери операцию группой **M2–M0**. Веса слева направо: `4`, `2`, `1`. Например, для умножения (`010`) включи только `M1`.
3. **После последнего переключения дождись заполнения шкалы.** Наблюдатель под каждым рычагом запускает сброс. Сигнал сброса проходит по проводам, гасит табло и обнуляет шкалу. Затем ниже цифр загораются десять делений слева направо. Если поправишь число или режим, отсчёт начнётся заново; отдельной кнопки нет. Шкала 100% означает, что ответ уже стабилен.
4. Когда шкала заполнится, считай обычное десятичное число. Ведущие нули не выводятся (`7`, не `00007`). Слева зажигается минус для отрицательного результата. При делении на ноль цифры не загораются, а справа включаются лампы **«Ошибка»**. Двоичный ряд ниже шкалы работает напрямую и может меняться раньше табло.

| M2 M1 M0 | Код | Операция | Пример |
| --- | ---: | --- | --- |
| `000` | 0 | Сложение | `255 + 255 = 510` |
| `001` | 1 | Вычитание | `42 − 87 = −45` |
| `010` | 2 | Умножение | `197 × 19 = 3743` |
| `011` | 3 | Целочисленное деление | `197 ÷ 19 = 10` |
| `100` | 4 | Остаток от деления | `197 % 19 = 7` |
| `101` | 5 | Побитовое И (AND) | `181 AND 61 = 53` |
| `110` | 6 | Побитовое ИЛИ (OR) | `181 OR 61 = 189` |
| `111` | 7 | Побитовое исключающее ИЛИ (XOR) | `181 XOR 61 = 136` |

**Пример:** `A = 197`, `B = 19`, `M = 010` → `3743`. Не меняя A и B, включи ещё `M0`: шкала сбросится, табло выдаст частное `10`. Затем выключи `M1` и `M0`, включи `M2` — получишь `7`.

Это целочисленный калькулятор: дробей и отрицательного ввода нет. Максимум по модулю — `65 025` (`255 × 255`). **Шкала измеряет выдержку редстоун-таймера**, а не количество выполненных арифметических шагов. Она одинаковая для всех режимов. Расчётный путь до табло занимает до 2 502 игровых тиков; короткие примеры тоже проходят весь таймер. На один цикл закладывай **до 3 мин 30 с при 20 TPS**. Если сервер не держит 20 TPS, в реальном времени цикл займёт дольше. В GIF ожидание сжато.

## Вставка

1. Положи `.litematic` в `schematics` профиля **Java 26.3** с Litematica и MaLiLib. Выбери **M → Load Schematics**, затем **Paste Schematic in World** в творческом режиме. В одиночном тестовом мире оставь `pasteUsingCommandsInSp=false` для прямой вставки с NBT: в нём сохранены сила сигнала компараторов и подписи.
2. Вставляй обновлённую схему целиком на пустой участок, а не поверх прежней версии: внутренняя проводка изменилась. Для первого запуска подойдёт плоский мир и поворот 0°. Оставь объём **267 × 155 × 273** (X × Y × Z, **527 410 блоков** без воздуха). Точка привязки — нижний северо-западный угол. Пульт смотрит на север (`−Z`). При начале `(0, 72, 0)` к рычагам удобно подлететь около `(53, 81, 4)`, лицом на юг; чтобы увидеть табло целиком, отлети чуть севернее. Для вставки встань над центром, чтобы клиент видел весь объём.
3. **Все чанки схемы должны тикать**, пока стоишь у пульта. В тестовом мире с началом `X=0, Z=0` закрепи их на время расчёта:

   ```mcfunction
   /forceload add 0 0 127 272
   /forceload add 128 0 266 272
   ```

   Для другого начала прибавь его X и Z к координатам. Для снятия закрепления используй `remove` с теми же границами.
4. Сохранённое состояние — `0 + 0`, на экране `0`, шкала полная. В тестовом мире с правами можно ускорить один прогон через `/tick sprint 4200t` после ввода. Это необязательно: в обычном режиме используется только редстоун.

## Как устроено

- Арифметический блок складывает, вычитает, умножает частичными произведениями, делит пробными вычитаниями и выполняет побитовые операции. Сигналы `0/15` обрабатываются вычитающими компараторами, повторителями, пылью и факелами.
- Двоичный ответ преобразуется в пять разрядов BCD по алгоритму «сдвиг и добавь три», затем дешифратор включает семь сегментов каждой цифры. Сегменты, знак, ошибка и деления шкалы подключены реальной проводкой. Всего на фасаде **231 редстоун-лампа**, включая двоичный ряд.
- Импульсы наблюдателей объединяются и растягиваются цепочкой повторителей. Сброс перекрывает входы десяти задержек и даёт им погаснуть перед новым циклом. Они не образуют непрерывно работающих часов. Последнее деление шкалы ждёт, пока сигнал разрешения дойдёт до цифр.

## Пересборка и проверки

Чисто булева логика арифметики проверена для всех **524 288** комбинаций A/B/M. Отдельный тест десятичного декодера покрывает все **65 536** 16-битных слов, в том числе гашение ведущих нулей. На ванильном сервере из экспортированной схемы проверены холодное `0`, `65025`, отрицательный ответ и ошибка. При изменении входов посреди расчёта шкала сбросилась с `3/10` до `0/10`, затем прошла промежуточные деления и дошла до `10/10`. Тест считывает каждый пиксель. Это проверка самой схемы, не клиентской вставки через Litematica.

```sh
python -m pip install -r requirements.txt
# Нужен C++17; кэш трасс — необязательный временный файл.
python -m tools.build_calculator --routing-cache /tmp/moonspire-calculator-routes.txt
# Assets клиента Java 26.3; для подписей — шрифты DejaVu.
python -m tools.render_calculator /path/to/assets/minecraft
python -m tools.build_calculator --routing-cache /tmp/moonspire-calculator-routes.txt \
  --preview moonspire-calculator-preview.jpg
python -m unittest discover -s tests -p 'test_calculator.py' -v
```

Принимая [Minecraft EULA](https://aka.ms/MinecraftEULA), запусти официальный `server.jar` Java 26.3 под Java 25:

```sh
python -m tools.verify_calculator --server /path/to/server.jar --accept-minecraft-eula --quick
# Короткий набор с обновлениями соседних блоков во время вставки:
python -m tools.verify_calculator --server /path/to/server.jar --accept-minecraft-eula --neighbor-updates --smoke
```
