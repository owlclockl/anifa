# Мастерская хранителей: один вход для всего склада

[Разрез и маршруты](../moonspire-cathedral-catacombs-logistics.png) · [GIF работы](../moonspire-cathedral-catacombs-logistics.gif) · [План катакомб № 9](../moonspire-cathedral-catacombs-map.png) · [Отдельный компактный склад без собора](compact-store.md)

Из западного коридора кольца у входа в кладовую поднимись по каменной лестнице в цех, затем по деревянной — на балкон. **Сундук «Приёмка» один:** в него можно одновременно класть обычные предметы, заполненные и пустые шалкеры. Рычаг рядом останавливает подачу **из** сундука: предметы, уже ушедшие в механизм, продолжат путь, а водовод не перекрывается. При вставке рычаг выключен. Скрытый сундук старой линии — буфер, а не второй вход.

- **Шалкеры.** Автомат принимает окрашенные и неокрашенные коробки. Сначала он опустошает коробку, затем ломает её поршнем в закрытой камере. Пустую коробку с тем же цветом и именем забери из сундука **«Пустые шалкеры»** на уровне цеха. Получать коробки нужно именно там: они не выбрасываются в проход и не возвращаются в приёмку.
- **Ресурсы.** Вещи из коробок и насыпью идут по одной линии. Сначала она предлагает их сборщикам. Неподходящие и излишки уходят к прежним 36 фильтрам и дальше в «Остаток». Например, кварц останется кварцем и попадёт в свою бочку — кварцевый блок не разбирается обратно в кварц.
- **Фермы.** В центре оранжереи находится ограждённая горловина. В неё можно бросить урожай либо подвести выход фермы с предметами. Предметы идут по закрытому водоводу из 215 блоков и через внутренний буфер попадают **в тот же сундук «Приёмка»**. Это транспорт: грядки не собирают и не пересаживают себя. Пшеница прессуется в снопы, морковь, картофель и семена идут в «Остаток».

## Что уплотняется

20 отдельных сборщиков, по пять в каждом из четырёх рядов. У каждого свой предзаполненный фильтр, выходная бочка и лампа буфера. Девять одинаковых обычных предметов дают одну единицу продукта; остаток меньше девяти ждёт следующей подачи в сетке сборщика. Все перечисленные продукты можно разобрать **обычным крафтом** обратно в девять исходных предметов. Дополнительный этап не запускается сам: например, слитки из самородков выдаются в отдельной бочке; чтобы получить из них блоки, подай слитки в общий вход ещё раз.

| Ряд (с севера) | 9 исходников → 1 продукт |
| --- | --- |
| 1 | Железные слитки → железный блок; медные слитки → медный блок; золотые слитки → золотой блок; алмазы → алмазный блок; изумруды → изумрудный блок |
| 2 | Рудное железо, рудная медь и рудное золото → их рудные блоки; уголь → угольный блок; редстоун → блок редстоуна |
| 3 | Лазурит → лазуритовый блок; незеритовые слитки → незеритовый блок; железные, медные и золотые самородки → соответствующие слитки |
| 4 | Сгустки слизи → слизневый блок; пшеница → сноп; костная мука → костный блок; сушёная ламинария → блок сушёной ламинарии; сгустки смолы → блок смолы |

Это все однородные обратимые рецепты **9 → 1 → 9** из ванильного Java 26.3. Не добавлены рецепты с потерей исходника, с особыми ингредиентами (например, мёд и бутылочки) и плавка. Переименованные экземпляры не смешиваются с обычными и не крафтятся.

## Индикация и безопасная остановка

| Где горит | Что делать |
| --- | --- |
| «Сундук полон» у приёмки | Дай линии время или освободи выходы. Рычаг рядом временно закрывает подачу из общего сундука. |
| «С ферм» у потолка балкона | В буферном сундуке водовода ждут предметы. Лампа не считывает две воронки под ним, поэтому небольшая партия может задержаться в них без сигнала. Если свет не гаснет, останови подачу урожая, проверь приёмку и выходы. |
| «Есть коробки» | Забери пустые шалкеры. Если выход полон, новые коробки остаются в закрытых контейнерах; после освобождения выдача продолжится. |
| Рядом с бочкой сборщика | В выходной воронке ждёт блок. Короткая вспышка нормальна; при постоянном свете освободи бочку. Сборщик не выбрасывает продукты наружу. |
| «Остаток» в нижнем зале | В нижнем сундуке есть необработанные предметы. Освободи оба сундука, если очередь остановилась. |

**Скорость ограничена последовательной проверкой предметов.** Это склад для пакетной подачи, не магистраль для непрерывной промышленной фермы. В нагрузочном тесте партия из 27 стопок (1 728 предметов) обработалась примерно за час в пересчёте на 20 TPS; пустая коробка вернулась раньше. Водовод переносит сущности предметов: временный буфер и сундук не бездонны, поэтому не подавай урожай в уже заполненную систему. При переполнении даже водного буфера непойманные предметы могут исчезнуть по обычному таймеру Minecraft. Для доставки нужны симулируемые чанки **по всему маршруту** от оранжереи до кладовой; при выгрузке транспорта доставка ждёт загрузки. Не закрывай ворота внутри трубы: на них сделаны разрывы между водными секциями. Воду и ледяное дно не заменяй.

## Расположение и вставка

Координаты — смещения от нижнего северо-западного угла `.litematic` без поворота. При начале на `Y=29` кольцо на `Y=37`, пол цеха на `Y=47`, общий сундук на `Y=62`.

| Место | ΔX | ΔY | ΔZ |
| --- | ---: | ---: | ---: |
| Подножие лестницы от кольца | 133 | 8 | 219 |
| Общая приёмка (обе половины) | 133–134 | 33 | 221 |
| Выдача пустых шалкеров | 147–148 | 19 | 226 |
| Бочки сборщиков | 131, 139, 147, 155, 163 | 19 | 173, 187, 201, 215 |
| Водовод: горловина оранжереи | 35 | 43 | 106 |

Вставляй блоки **с NBT и инвентарями** (`pasteIgnoreInventories=false`). В творческом одиночном мире используй прямую вставку (`pasteUsingCommandsInSp=false`); при командной вставке требуется восстановление NBT. Не забирай метки или запас из фильтров, не ешь технические торты: они задают эталонный сигнал компараторов. Сохрани состояние воды и сделай резервную копию мира перед вставкой. [Подробности об обычных фильтрах](catacombs-storage.md).

## Воспроизвести проверки

[`tools/verify_logistics.py`](../tools/verify_logistics.py) ставит вырезки из **финального экспортированного `.litematic`** на официальном [сервере Java 26.3](https://piston-data.mojang.com/v1/objects/33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c/server.jar). Нужны зависимости из `requirements.txt`, Java 25+ и принятие [Minecraft EULA](https://aka.ms/MinecraftEULA):

```sh
python -m tools.verify_logistics --server /path/to/server.jar --accept-minecraft-eula
python -m tools.verify_logistics --server /path/to/server.jar --accept-minecraft-eula --neighbor-updates
# Отдельный нагрузочный прогон: один полный шалкер, 27 стопок
python -m tools.verify_logistics --server /path/to/server.jar --accept-minecraft-eula --neighbor-updates --full-shulker
```

В обоих режимах основной сценарий проверяет калибровку и заполнение фильтров, паузу и датчик полного сундука, 20 рецептов по данным ванильной игры, 17 вариантов шалкера, возврат пустых коробок, имена груза и перезапуск посреди распаковки. Он отправляет урожай от горловины, проверяет лампу очереди и доставку именно в общий сундук, а также заполняет линию выдачи коробок и бочку сборщика и проверяет возобновление после освобождения места. Это тест на ванильном сервере, не тест полной клиентской вставки Litematica. Разрезы отрисованы из схемы; стрелки и условные значки предметов в GIF добавлены для наглядности.
