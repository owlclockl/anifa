# Кладовая хранителей

В «Печати глубин» прежний зал с **36 готовыми фильтрами** объединён с [Мастерской хранителей](catacombs-logistics.md). Вход **№ 9** на [плане катакомб](../moonspire-cathedral-catacombs-map.png): от мозаичного компаса Распутья ключей иди на север к Галерее имён, сверни направо под табличку «Автосклад».

**Одна общая приёмка на верхнем балконе** принимает смесь обычных предметов и шалкеров. От входа поднимись по каменной лестнице в цех, затем по деревянной к сундуку. Пустые коробки забирай в цехе, сжатые ресурсы — в бочках сборщиков. Старая приёмка за стеклом теперь внутренний буфер, открывать её не нужно.

Дальше в нижнем зале работают подписанные отсеки: **две бочки на предмет, всего 54 стака**. Заполняется сначала нижняя бочка, затем верхняя. Если для ресурса есть сборщик, в обычные бочки он приходит при переполнении цеха. Неподходящие предметы и излишки забирай из двух двойных сундуков **«Остаток»**. Лампа показывает вещи в нижнем сундуке.

Забирай остаток вовремя: если оба сундука полны, очередь дойдёт до входа и остановится до освобождения места. Секция не забирает вещи назад из «Остатка» — их можно снова подать в общий сундук. Старый участок пропускает примерно 2,5 предмета/с при 20 TPS, но вся система работает медленнее из-за проверки на шалкеры. Кладовая не зависит от фуникулёра.

## Какие фильтры стоят

Фильтры принимают обычные, не переименованные версии указанных предметов. Каждая группа — шесть подписанных отсеков; порядок ниже совпадает с направлением сортировки, с запада на восток в северном ряду и обратно в южном.

| Ряд | Группа | Предметы |
| --- | --- | --- |
| Северный | Кладка | Булыжник, камень, каменные кирпичи, дроблёный глубинный сланец, глубинносланцевые кирпичи, глубинносланцевая плитка |
| Северный | Камень глубин | Туф, туфовые кирпичи, полированный туф, чернит, кирпичи из полированного чернита, базальт |
| Северный | Земля и стекло | Земля, гравий, песок, стекло, кальцит, скалк |
| Южный | Плавильня | Железный, медный и золотой слитки, рудное железо, рудная медь, уголь |
| Южный | Редкие запасы | Редстоун, лазурит, алмаз, изумруд, кварц, осколок аметиста |
| Южный | Припасы | Дубовое бревно, бревно тёмного дуба, еловое бревно, доски тёмного дуба, бумага, кость |

**Фильтры и их содержимое записаны в `.litematic`.** В каждой фильтрующей воронке уже лежат 41 целевой предмет и четыре поштучные «Метки кладовой». Выходная воронка под ней предварительно заполнена пятью стаками того же предмета. Она заперта факелом и при срабатывании сначала отдаёт одну штуку в бочку, затем берёт взамен одну из фильтра. Так до выдачи доходит даже одиночный предмет. Заполнение секции не опустошает соседние фильтры. Обычная бумага и метки не складываются вместе. Эти две воронки — часть схемы, не запас для игрока; не вынимай их содержимое. Приёмка, бочки выдачи и остаток изначально пусты.

## Вставка с содержимым

В **Litematica → Generic** оставь `pasteIgnoreInventories=false`. В одиночном творческом мире используй **Paste Schematic in World** с обычной прямой вставкой (`pasteUsingCommandsInSp=false`). В мультиплеере нужен способ вставки с восстановлением **NBT блоков**: одного `pasteIgnoreInventories=false` недостаточно, если на сервер отправляются только состояния блоков. При `pasteNbtRestoreBehavior=NONE` командная вставка не восстанавливает содержимое. Если сервер всё равно отбрасывает NBT, не начинай большой разгрузкой: проверь способ вставки на копии мира. Ручное строительство по голограмме само по себе не переносит инвентари.

Проверка после вставки: положи в общий сундук один обычный булыжник и одну булыжную ступеньку. Булыжник должен появиться в своей бочке, ступенька — в «Остатке». Дай линии около двух минут с загруженными чанками. Если булыжник в «Остатке», проверь, сохранилось ли содержимое фильтров.

При установке без поворота смещения от нижнего северо-западного угла схемы:

| Место | ΔX | ΔY | ΔZ |
| --- | ---: | ---: | ---: |
| Порог кладовой (пол) | 138 | 8 | 220 |
| Общий сундук на балконе | 133–134 | 33 | 221 |
| Возврат пустых шалкеров | 147–148 | 19 | 226 |
| Остаток, две пары половин | 141–142 | 9 и 11 | 226 |

Если начало схемы на `Y=29`, порог на `Y=37`, приёмка на `Y=62`. Сохраняй `minecraft:light` и делай резервную копию мира перед вставкой.

## Повторить ванильную проверку

[`tools/verify_storage.py`](../tools/verify_storage.py) берёт блоки **и NBT** из области кладовой в готовом `.litematic`, загружает их как шаблон в одноразовый мир ванильного Java 26.3 и проверяет инвентари в игре. Нужны зависимости из `requirements.txt`, Java 25+, [официальный `server.jar` 26.3](https://piston-data.mojang.com/v1/objects/33680f5f2ac32864d6d7cf5e56a705fdb3e05f4c/server.jar) и принятие [Minecraft EULA](https://aka.ms/MinecraftEULA):

```sh
python -m tools.verify_storage --server /path/to/server.jar --accept-minecraft-eula
python -m tools.verify_storage --server /path/to/server.jar --accept-minecraft-eula --neighbor-updates
```

Этот регрессионный тест подаёт предметы прямо во внутренний буфер, чтобы проверить прежнюю линию отдельно. [Сквозная проверка общей приёмки и водовода](catacombs-logistics.md#воспроизвести-проверки). В каждом режиме проверяются холодный старт без выдачи запасов, 315 предметов вперемешку (все 36 отсеков и остаток), перезапуск мира во время сортировки, переполнение секции без сбоя соседей и возобновление выдачи после освобождения бочек. Это тест вырезки из экспортированной схемы в ванильной игре, **не** тест полной вставки клиентом Litematica или работы на сервере с изменённой механикой воронок.
